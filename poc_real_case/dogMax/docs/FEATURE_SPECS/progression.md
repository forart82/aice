# Progression Feature Spec

Updated: 2026-07-07

## Current Behavior

- Hero levels from XP gained on enemy kills.
- XP scales with enemy level, enemy tier, level delta, and kill streaks.
- Hero and weapon stats scale by level.
- Enemy level scales with traveled distance using the configured level curve.
- Dice level gates and quality/luck systems influence long-run power.

## Target Behavior

- The first 10 minutes should clearly show why leveling, loot quality, dice, and
  Dron matter.
- Long runs should create escalating build identity, not only bigger numbers.
- Progression should support both short-session play and future deeper ARPG
  structure.

## Open Questions

- What should persist between runs, if anything?
- Should the game prioritize roguelike run progression or ARPG account-style
  progression first?
- How should late-game power be capped without killing build fantasy?

## Do Not Do Yet

- Do not build permanent meta-progression until the single-run loop is easier to
  understand.
- Do not retune the full XP curve without a clear target run length.
