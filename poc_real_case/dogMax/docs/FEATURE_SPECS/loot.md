# Loot Feature Spec

Updated: 2026-07-07

## Current Behavior

- Enemies can drop weapons and dice.
- Items have quality, item level, stats, and scaling.
- Inventory, sidebar, weapon slots, dice sockets, powder, loot filter, and
  DiceCrafter systems exist.
- Powder supports destroying/converting items and fuels crafting verbs.

## Target Behavior

- Loot should feel like Path of Exile compressed into horde-game speed.
- The player should quickly understand whether an item improves the current
  build, opens a new build, or should become powder.
- Dice should feel like build-defining modifiers, not generic stat sticks.

## Open Questions

- What is the minimum item comparison UI needed for fast decisions?
- Should loot filter defaults protect the player from low-value clutter early?
- How should the game surface "this dice combination creates this Dron pattern"?

## Do Not Do Yet

- Do not add more item tiers before comparison and filtering are clear.
- Do not add complex crafting recipes until Reface/Evolve are better explained.
