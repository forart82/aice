# GEMINI.md — dogmax

The agent protocol for this project is **one document**, and it is
[`AGENTS.md`](AGENTS.md).

The original dogV6 repository carried `AGENTS.md` and `GEMINI.md` as two
byte-identical copies. That is a defect, not a feature: two copies of a mandatory
ruleset drift, and once they drift there is no way to tell which one is binding.

**Read [`AGENTS.md`](AGENTS.md) and [`ORACLE.md`](ORACLE.md).**

- `AGENTS.md` — TDD protocol, the 15 rules, the operational workflow
- `ORACLE.md` — the Single Source of Truth for game rules and formulas
- `CLAUDE.md` — Claude Code project facts, subordinate to both of the above
