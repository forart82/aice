# AICE Architecture & Codebase Map

> Compact architecture map for AI agents. Pure On-the-Fly AI Context Engine (`outline` -> `context` -> `splice` + `$idioms`) with zero `.aice` files on disk.

## Core Workflows & Entrypoints
- **CLI Compiler & On-the-Fly Tools**: `bin/aice.ts` -> `bin/aice.mjs`
- **Library Root**: `src/index.ts`
- **MCP Server**: `src/mcp/server.ts` (`aice mcp`, stdio JSON-RPC tools)

## Directory Map (`src/`)
- `src/core/`: Lexer, Pratt Parser (`parser.ts`), AST definitions (`ast.ts`), Token definitions, Span tracking, Trivia tables (`trivia.ts`).
- `src/decompiler/`: Universal in-memory reverse transpiler (`index.ts`, `aice-generator.ts`, `ts-decompiler.ts`, `go-decompiler.ts`, `rust-decompiler.ts`, `cpp-decompiler.ts`, `csharp-decompiler.ts`, `kotlin-decompiler.ts`, `php-decompiler.ts`, `py-decompiler.ts`, `css-decompiler.ts`, `html-decompiler.ts`, `data-decompiler.ts`, `twig-decompiler.ts`). 15 target dialects -> canonical AICE AST in RAM.
- `src/emitters/`: AST-to-target code generators (`index.ts`, `rewriter.ts`, `ts-emitter.ts`, `go-emitter.ts`, `rust-emitter.ts`, `cpp-emitter.ts`, `csharp-emitter.ts`, `kotlin-emitter.ts`, `php-emitter.ts`, `py-emitter.ts`, `css-emitter.ts`, `html-emitter.ts`, `data-emitter.ts`, `twig-emitter.ts`). Targets: TS, TSX, JS, Python, Go, Rust, C++, C#, Kotlin, PHP, CSS, HTML, JSON, YAML, Twig.
- `src/typechecker/`: Sound static type inference (`checker.ts`, `types.ts`), cross-file module resolution, machine-readable JSON diagnostics & 1-shot self-repair (`diagnostics.ts`).
- `src/idioms/`: Native-first BPE-gated Smart Multi-File Idiom engine (`idiom-miner.ts`, `idiom-transform.ts`, `registry.ts`). Mines repetitive expressions & statement blocks directly from native files, caches provenance in `.aice-cache/idioms.json`, loads custom project idioms from `aice.config.json` or `.aice-idioms.json`, and supports multi-file read (`aice idioms read`), smart multi-file mutation (`aice idioms update`), and instant toggle (`aice idioms on|off`).
- `src/tools/`: Token-dense On-the-Fly productivity tools: `outline.ts` (85-95% token reduction AST structural skeleton), `context.ts` (1-turn dependency & symbol-scoped `-s` context pack across all 15 dialects with collapsed `$idioms`), `splice.ts` (forgiving direct-to-native surgical AST replace/delete/batch splice across `.ts/.tsx/.js/.py/.go/.rs/.cpp/.cs/.kt/.php/.css/.html/.json/.yaml/.twig`), `fmt.ts`, `diff.ts`, `patch.ts`, plus the progressive benchmark runners (`benchmark-100-cases.ts`, `benchmark-500-cases.ts`, `benchmark-500-per-language.ts`).
- `src/cache/`: Persistent disk CST/AST caching (`cache-store.ts`).
- `src/config/`: Project configuration (`aice.config.json`, `.aice-idioms.json`), on-the-fly path resolution (`project-config.ts`, `path-resolver.ts`).
- `src/tokenomics/`: BPE tokenizer benchmarking (`tiktoken.ts`, `token-auditor.ts`), drift verification, and empirical telemetry.
- `src/mcp/`: First-Class Model Context Protocol server (`server.ts`) exposing `aice_context`, `aice_outline`, `aice_splice`, and `aice_idioms`.

## Key CLI Commands (`bin/aice.ts`)
- `aice outline <path> [-d <depth>] [--idioms] [--stats]`: Generate token-dense AST structural skeleton on-the-fly from native files
- `aice context <path> [-s <symbol>] [-d <depth>] [--max-tokens <n>] [--idioms|--no-idioms]`: Generate 1-turn agent context bundle with symbol slicing and collapsed `$idioms`
- `aice splice <path> -s <symbol> [-c <code> | --body <code> | --delete | --batch <json>] [--idioms] [--dry-run] [--in-place]`: Forgiving direct-to-native surgical AST splice (accepts pure AICE, `$idioms`, raw native code, or hybrid Frankenstein syntax)
- `aice idioms <scan|read|update|on|off|apply|expand|list> [dir]`: Mine, inspect, toggle, and mutate Smart Multi-File Idioms across native files
- `aice decompile <file>` / `aice compile <file>` / `aice roundtrip <file>`: In-memory decompile, compile, or verify lossless lens stability
- `aice verify <file> [--json]` / `aice fix <file> [--dry-run]`: Typecheck and autonomously repair violations
- `aice mcp`: Start Model Context Protocol server over stdio

## Validation & Benchmark Commands
- `npm run check`: Typecheck codebase (`tsc --noEmit`) with zero errors
- `npx vitest run`: Run entire unit test suite (46 test files, 1,259 tests)
- `npm run benchmark:offline`: Run deterministic offline 3-way benchmark (`docs/BENCHMARKS_OFFLINE.md`)
- `npm run benchmark`: Run live real-agent 3-way benchmark (`docs/BENCHMARKS.md`)
