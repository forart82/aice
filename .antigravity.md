# AIL Architecture & Codebase Map

> Compact architecture map for AI agents. Token-efficient homoiconic bidirectional compiler & tooling.

## Core Workflows & Entrypoints
- **CLI Compiler & Tools**: `bin/ail.ts` -> `bin/ail.mjs`
- **Library Root**: `src/index.ts`
- **LSP Daemon**: `src/lsp/server.ts` (`ail lsp`, JSON-RPC 2.0 stdio)
- **MCP Server**: `src/mcp/server.ts` (`ail mcp`, stdio JSON-RPC tools)

## Directory Map (`src/`)
- `src/core/`: Lexer, Pratt Parser (`parser.ts`), AST definitions (`ast.ts`), Token definitions, Span tracking, Trivia tables (`trivia.ts`).
- `src/decompiler/`: Universal reverse transpiler (`index.ts`, `ail-generator.ts`, `ts-decompiler.ts`, `go-decompiler.ts`, `rust-decompiler.ts`). 14+ target dialects -> canonical `.ail`.
- `src/emitters/`: AST-to-target code generators (`index.ts`, `rewriter.ts`, `ts-emitter.ts`, `go-emitter.ts`, `rust-emitter.ts`). Targets: TS, JS, TSX, Python, Go, Rust, Kotlin, PHP, C++, C#, CSS, HTML, JSON, YAML, Twig.
- `src/typechecker/`: Sound static type inference (`checker.ts`, `types.ts`), cross-file module resolution, machine-readable JSON diagnostics & 1-shot self-repair (`diagnostics.ts`).
- `src/idioms/`: Native-first BPE-gated Smart Multi-File Idiom engine (`idiom-miner.ts`, `idiom-transform.ts`). Mines repetitive expressions & statement blocks directly from native files, caches provenance in `.ail-cache/idioms.json`, and supports multi-file read (`ail idioms read`), smart multi-file mutation (`ail idioms update`), and instant toggle (`ail idioms on|off`).
- `src/watcher/`: Incremental watch daemon (`ail-watch.ts`) with sub-5ms recompile, HMR preservation, and bidirectional companion target-to-AIL reverse sync with write-loop suppression.
- `src/shield/`: AI cognitive protection (`ai-shield.ts`), Twinless & Side-by-Side PreToolUse hooks (`.agents/hooks.json`), `.cursorignore`, `.vscode/settings.json`, and atomic filesystem locks (`chmod 444`).
- `src/transpiler/`: Side-by-side and companion twin workspace ingestion engine (`parallel-ingest.ts`, `eject.ts`).
- `src/tools/`: Token-dense On-the-Fly productivity tools: `context.ts` (1-turn dependency & symbol-scoped `-s` context pack across all 15 dialects), `outline.ts` (85-95% token reduction AST skeleton), `splice.ts` (forgiving direct-to-native surgical AST replace/delete/batch splice across `.ts/.tsx/.js/.py/.go/.rs/.cpp/.cs/.kt/.php/.css/.html/.json/.yaml/.twig`), `benchmark-100-cases.ts` (100-case deep Twinless benchmark suite), `benchmark-500-cases.ts` (500-case progressive benchmark suite `#001..#500`), `benchmark-500-per-language.ts` (15 × 500 = 7,500 per-language progressive benchmark suite), `fmt.ts`, `diff.ts`, `patch.ts`.
- `src/evolve/`: 5-Gate differential fuzzing, self-healing campaign loop & AST fuzzer (`evolution-loop.ts`, `ast-fuzzer.ts`).
- `src/cache/`: Persistent disk CST/AST caching (`cache-store.ts`).
- `src/config/`: Project configuration (`ail.config.json`), mode resolution (`twinless`, `side-by-side`, `isolated`, `companion`), and path targets (`project-config.ts`, `path-resolver.ts`).
- `src/runner/`: Test execution harness (`test-runner.ts`), V8 stack trace translator (`symbol-error-formatter.ts`), ConcurrencyPool & terminal reporters.
- `src/tokenomics/`: BPE tokenizer benchmarking (`tiktoken.ts`, `token-auditor.ts`), drift verification, and empirical telemetry.
- `src/lsp/`: Language Server Protocol implementation (`server.ts`, `analyzer.ts`, `protocol.ts`) supporting hovers, symbols, formatting, quickfix self-repair, and `$idiom` navigation.
- `src/mcp/`: First-Class Model Context Protocol server (`server.ts`) exposing `ail_context`, `ail_outline`, `ail_splice`, `ail_idioms`, `ail_test`, and `ail_evolve`.

## Key CLI Commands (`bin/ail.ts`)
- `ail outline <path> [-d <depth>]`: Generate token-dense AST structural skeleton on-the-fly from native or `.ail` files
- `ail context <path> [-s <symbol>] [-d <depth>] [--max-tokens <n>] [--idioms|--no-idioms]`: Generate 1-turn agent context bundle with symbol slicing and collapsed `$idioms`
- `ail splice <path> -s <symbol> [-c <code> | --body <code> | --delete | --batch <json>]`: Forgiving direct-to-native surgical AST splice (accepts pure AIL, `$idioms`, raw native code, or hybrid Frankenstein syntax)
- `ail idioms <scan|read|update|on|off|apply|expand|list> [dir]`: Mine, inspect, toggle, and mutate Smart Multi-File Idioms across native files
- `ail shield apply [dir] [--twinless]`: Deploy Twinless or Side-by-Side cognitive rules and PreToolUse hooks
- `ail compile <file>` / `ail decompile <file>` / `ail roundtrip <file>`: Compile, decompile, or verify lossless lens stability
- `ail adopt [dir] [--companion <targetDir>] [--idioms]`: Ingest codebase into side-by-side or companion twin workspace
- `ail watch [dir] [--bidirectional]` / `ail sync [dir]`: Incremental build daemon and target-to-AIL sync
- `ail test [target] [--json]`: Run test suite with symbol-mapped error traces
- `ail evolve [-r <restarts>] [-c <cycles>] [--seed <n>]`: Run autonomous 5-gate differential evolution loop
- `ail lsp` / `ail mcp`: Start Language Server Protocol daemon or Model Context Protocol server
- `ail verify <file> [--json]` / `ail fix <file> [--dry-run]`: Typecheck and autonomously repair violations
- `ail eject [dir]`: Restore target codebase and remove shields

## Validation & Test Commands
- `npx vitest run`: Run entire test suite (1,623 tests across 68 test files)
- `npm run benchmark:100`: Run the 100-Case Deep Twinless On-the-Fly Benchmark Suite (`docs/BENCHMARK_100_ON_THE_FLY.md`)
- `npm run benchmark:500`: Run the 500-Case Progressive On-the-Fly Benchmark Suite (`docs/BENCHMARK_500_ON_THE_FLY.md`)
- `npm run benchmark:500:languages`: Run the 500-Per-Language & File-Type Progressive Benchmark Suite (15 × 500 = 7,500 cases, `docs/BENCHMARK_500_PER_LANGUAGE.md`)
- `npm run check` / `npx tsc --noEmit`: Typecheck codebase with zero errors
