# AICE Architecture & Codebase Map

> Compact architecture map for AI agents. Pure-Rust 100% On-the-Fly AI Co-Engine (`read` -> `search` / `find` -> `splice`) with zero `.aice` files on disk.

## Core Workflows & Entrypoints
- **CLI Entrypoint**: `crates/aice-cli/src/main.rs` (`run_cli` in `crates/aice-cli/src/lib.rs`)
- **Type-State Pipeline Core**: `crates/aice-pipeline/src/executor.rs` (`Raw -> Governed -> Executed -> MeteredOutput -> StdoutWriter`)
- **MCP Stdio Server**: `crates/aice-cli/src/mcp_server.rs` (`aice mcp`, strict 2-tool JSON-RPC: `aice_read`, `aice_splice`)

## Workspace Crates (`crates/`)
- `crates/aice-governance/`: `aice.config.json` / `.aicerc` discovery, `enabled` gate, `allowedReadRoots` path guard, NUL/UTF-8 binary probe, `AGENTS.md` sync, and MCP/agent config wiring.
- `crates/aice-lang-registry/`: `LanguageId` (23 R5 incl. Twig + 9 R6 DB/query + `PlainText`), detection, and core traits (`LanguageAdapter`, `AstSlicer`, `SyntaxFirewall`).
- `crates/aice-ast-engine/`: 25 `tree-sitter` grammar adapters, strict Rust RD parsers (Twig, T-SQL, PL/pgSQL, Cypher, migrations), intra-function AST slicing, dependency graph, and pre-write `SyntaxFirewall`.
- `crates/aice-aice-ir/`: Bidirectional AICE IR AST, lexer/parser/printer, and `DefaultAiceTranspiler`.
- `crates/aice-find-engine/`: Parallel ignore-aware walker and trigram + AST symbol fuzzy guesser.
- `crates/aice-telemetry/`: Honest `bpe-openai` (`cl100k_base` & `o200k_base`) metering, `gains.jsonl` / `errors.jsonl`, `gain` & `analyze`.
- `crates/aice-batch-read/`: Unified target/selector parser (`:`, `#`, `@`, `:L`, `/regex/`), water-filling token budget, topological ordering, deduplicated context pack, and 4-tier ranked `search`.
- `crates/aice-batch-write/`: Heredoc (`=== ... ===`, `<<< ... >>>`) & JSON batch manifest parser, 5-tier hunk/AST/line splicer, in-memory `SyntaxFirewall`, and atomic `.tmp -> rename` rollback.
- `crates/aice-pipeline/`: Compile-time type-state pipeline executor, `StdoutWriter` (sole stdout sink), subcommand help, MCP schema rendering, and in-process `benchmark`.
- `crates/aice-cli/`: Pure-`std` CLI parser, flag normalization, and strict 2-tool MCP stdio server.

## Key CLI Commands (`aice`)
- `aice read <targets...> [--outline | --full | --deps | --callers | --max-tokens <N> | --files | --stats]` (aliases: `context`, `ctx`): Universal AICE IR read with `#` & `:` selectors and intra-AST focus (`Sym@if`, `Sym@loop`, `Sym@first`).
- `aice search <pattern> [targets...] [-C <N> | -n | -l | -s <SEL> | --stats]` (alias: `grep`): 4-tier ranked search with AICE IR snippet transformation.
- `aice find [pattern] [targets...] [-d <N> | --full]` (alias: `tree`): Parallel ignore-aware file & fuzzy symbol discovery.
- `aice splice <path> [-s <SEL> -c <CODE> | --stdin]` (alias: `write`): Atomic AST, hunk (`<<< === >>>`), line-range, and multi-file heredoc/JSON batch splicer.
- `aice enable|disable|config|agents|gain|analyze|mcp|benchmark`: Project lifecycle, agent wiring, honest BPE telemetry, MCP server (`--generate-schemas`), and in-process benchmark (`bench`).

## Validation & Benchmark Commands
- `cargo build --release --offline`: Build native Linux release binary (`target/release/aice`)
- `RUSTFLAGS="-D warnings" cargo test --workspace --offline`: Run full Rust unit & integration test suite (including `golden_parity`, `modularity_gate`, `anti_bypass_audit`)
- `cargo clippy --workspace --all-targets --offline -- -D warnings`: Zero-warning Clippy lint check
- `python3 tools/check_line_limits.py`: Enforce `<= 300` lines per `.rs` file under `crates/*/src/**`
- `python3 tests/e2e/run_e2e.py --bin target/release/aice --tier all`: Run 215-case opaque-box E2E suite
