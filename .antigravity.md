# AIL Architecture & Codebase Map

> Compact architecture map for AI agents. Token-efficient homoiconic bidirectional compiler & tooling.

## Core Workflows & Entrypoints
- **CLI Compiler & Tools**: `bin/ail.ts` -> `bin/ail.mjs`
- **Library Root**: `src/index.ts`
- **LSP Daemon**: `src/lsp/server.ts` (`ail lsp`, JSON-RPC 2.0 stdio)
- **MCP Server**: `src/mcp/server.ts` (`ail mcp`, stdio JSON-RPC tools)

## Directory Map (`src/`)
- `src/core/`: Lexer, Pratt Parser (`parser.ts`), AST definitions (`ast.ts`), Token definitions, Span tracking, Trivia tables (`trivia.ts`).
- `src/decompiler/`: Universal reverse transpiler (`index.ts`, `ail-generator.ts`, `ts-decompiler.ts`, `go-decompiler.ts`, `rust-decompiler.ts`). 14+ target dialects -> canonical `.ail`.
- `src/emitters/`: AST-to-target code generators (`index.ts`, `rewriter.ts`, `ts-emitter.ts`, `go-emitter.ts`, `rust-emitter.ts`). Targets: TS, JS, TSX, Python, Go, Rust, Kotlin, PHP, C++, C#, CSS, HTML, JSON, YAML, Twig.
- `src/typechecker/`: Sound static type inference (`checker.ts`, `types.ts`), cross-file module resolution, machine-readable JSON diagnostics & 1-shot self-repair (`diagnostics.ts`).
- `src/idioms/`: Project-specific BPE-gated idiom engine (`idiom-miner.ts`, `idiom-transform.ts`). Collapses repetitive sub-ASTs into `$idiom($0, $1)` when net `cl100k_base` token savings >= 10.
- `src/watcher/`: Incremental watch daemon (`ail-watch.ts`) with sub-5ms recompile, HMR preservation, and bidirectional companion target-to-AIL reverse sync with write-loop suppression.
- `src/shield/`: AI cognitive protection (`ai-shield.ts`), PreToolUse hooks (`.agents/hooks.json`), `.cursorignore`, `.vscode/settings.json`, and atomic filesystem locks (`chmod 444`).
- `src/transpiler/`: Side-by-side and companion twin workspace ingestion engine (`parallel-ingest.ts`, `eject.ts`).
- `src/tools/`: Token-dense productivity tools: `context.ts` (1-turn dependency pack), `outline.ts` (85-90% token reduction AST skeleton), `splice.ts` (surgical AST replace/delete), `fmt.ts`, `diff.ts`, `patch.ts`.
- `src/evolve/`: 5-Gate differential fuzzing, self-healing campaign loop & AST fuzzer (`evolution-loop.ts`, `ast-fuzzer.ts`).
- `src/cache/`: Persistent disk CST/AST caching (`cache-store.ts`).
- `src/config/`: Project configuration (`ail.config.json`), mode resolution (side-by-side, isolated, companion), and path targets (`project-config.ts`, `path-resolver.ts`).
- `src/runner/`: Test execution harness (`test-runner.ts`), V8 stack trace translator (`symbol-error-formatter.ts`), ConcurrencyPool & terminal reporters.
- `src/tokenomics/`: BPE tokenizer benchmarking (`tiktoken.ts`, `token-auditor.ts`), drift verification, and empirical telemetry.
- `src/lsp/`: Language Server Protocol implementation (`server.ts`, `analyzer.ts`, `protocol.ts`) supporting hovers, symbols, formatting, quickfix self-repair, and `$idiom` navigation.
- `src/mcp/`: First-Class Model Context Protocol server (`server.ts`) exposing `ail_context`, `ail_outline`, `ail_splice`, `ail_idioms`, `ail_test`, and `ail_evolve`.

## Key CLI Commands (`bin/ail.ts`)
- `ail compile <file>`: Compile `.ail` to target dialect
- `ail decompile <file>`: Decompile target file into `.ail`
- `ail roundtrip <file>`: Verify Put(Get(c), Omega) == c lossless lens stability
- `ail adopt [dir] [--companion <targetDir>] [--idioms]`: Ingest codebase into side-by-side or companion twin workspace
- `ail watch [dir] [--bidirectional]`: Incremental build daemon with optional target-to-AIL reverse sync
- `ail sync [dir]`: One-shot bidirectional sync from targets back into `.ail`
- `ail idioms <scan|apply|expand|list> [dir]`: Mine and manage BPE-gated project idioms
- `ail context <path> [-d <depth>] [--max-tokens <n>]`: Generate 1-turn agent context bundle
- `ail outline <path> [-d <depth>]`: Generate token-dense AST structural skeleton
- `ail splice <path> -s <symbol> -c <code>`: Surgically modify AST symbol without whole-file rewrites
- `ail test [target] [--json]`: Run test suite with symbol-mapped error traces
- `ail evolve [-r <restarts>] [-c <cycles>] [--seed <n>]`: Run autonomous 5-gate differential evolution loop
- `ail lsp`: Start Language Server Protocol daemon
- `ail mcp`: Start Model Context Protocol server
- `ail verify <file> [--json]`: Typecheck and verify syntax soundness
- `ail fix <file> [--dry-run]`: Autonomously repair fixable violations
- `ail eject [dir]`: Restore target codebase and remove shields

## Validation & Test Commands
- `bun test`: Run entire test suite (1,546 tests across 63 test files)
- `bun test tests/unit/phase2_sync_lsp_mcp.test.ts`: Run Phase 2 Sync, LSP, and MCP test suite
- `bun run check` / `npx tsc --noEmit`: Typecheck codebase with zero errors
